# Changelog

## 0.1.0 — 2026-10-16

First playable single-player browser implementation of the supplied concept.

- Added 3D basement, first/third-person movement, tutorial gates, character definition and squad photo.
- Added a seeded starter town, job/connection dialogue, tent/lottery progression, trading and a vehicle.
- Added streamed road sections, searchable sites, food/water/fuel/condition, repairs and death.
- Added runtime modes and Apex/Sub behavior with interchangeable color themes.
- Added a world-settings editor, local floppy shelf, import/export and validated content folder scans.
- Added versioned browser saves with separate player/car positions and road return state.
- Added desktop/touch controls, paused dialogs and clear unavailable-feature labels.
- Preserved the studio website and custom-domain configuration; added a prototype link.
- Added simulation tests, browser acceptance tests, CI, run instructions, scope matrix and playtest checklist.

Known limitations and follow-on milestones are recorded in IMPLEMENTATION.md. This version is a prototype with placeholder meshes and no multiplayer service.
